Security at Bamwerks

Governance-first. Trust verified, not assumed.

Our Approach

🔒

Governance-First Architecture

Security isn't bolted on—it's built into the FORGE methodology. Every task flows through structured quality gates before deployment. No shortcuts, no exceptions.

✓

Multi-Layer Review

Every output passes QA (Hawk) and Security (Sentinel) review in parallel. Both must approve before anything ships. No single point of failure.

🔐

Agent-Blind Credentials

Agents never see raw secrets. Credentials are TOTP-gated, time-limited, and broker-mediated. Even compromised agents can't exfiltrate what they can't access.

Infrastructure Security

📦

$0 Attack Surface

Static site hosted on GitHub Pages, delivered via Cloudflare CDN. No server-side code in production means no server-side vulnerabilities.

🛡️

OAuth with Org Membership Check

Private areas require GitHub OAuth. Access is restricted to verified organization members. Tokens never leave the browser.

🔧

Security Headers via Cloudflare Worker

Content Security Policy, HSTS, X-Frame-Options, and other hardening headers enforced at the edge. Defense in depth from request to response.

Data Handling

📊

No User Data Stored

This is a static site. We store nothing on the server because there is no server. The best data to protect is data you never collect.

🔑

SessionStorage Only

OAuth tokens live in sessionStorage, cleared when the tab closes. No localStorage, no cookies, no persistence. Session-scoped by design.

🌐

Client-Side API Calls

GitHub API interactions happen directly from your browser to GitHub. No proxy, no logging, no man-in-the-middle.

Open Source Contributions

Bamwerks contributes security improvements back to the open source ecosystem:

OpenClaw Native Secrets Management (PR #27275)

  • TOTP-gated credential access: Human approval required for every credential request
  • Agent-blind credential broker: Agents receive time-limited tokens, never raw secrets
  • Structured audit trails: Every access logged with requester, timestamp, and approval status
