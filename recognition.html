Diamond Tier Providers

Generous free tiers that make $0 infrastructure possible.

GitHub

Repositories, Projects, Pages, and Actions — the backbone of our development workflow. The generous free tier hosts this very site.

Cloudflare

CDN, Workers, and DNS — keeps the site fast, auth secure, and the cost at zero.

Gold Tier Providers

The products and services we rely on every day.

Anthropic

Claude Code — the AI backbone of every agent. Claude models power all reasoning, code generation, and orchestration across the 40-agent swarm.

Apple

Mac mini — the quiet engine running the entire operation. Compact, efficient, and powerful enough to host 40 agents around the clock.

IONOS

Domain registration and DNS — the foundation that puts bamwerks.info on the map.

Open Source

The open source community makes ambitious projects like this possible. Thank you to every contributor.

OpenClaw

The agentic platform that makes Bamwerks possible. The runtime, orchestration, and tooling that brings our agents to life.

AWS Labs AI-DLC

AI-Driven Development Life Cycle methodology — one of the inspirations behind the FORGE workflow.

Everything Claude Code

Community-curated collection of Claude Code resources, tips, and workflows.

Next.js

The web framework powering this site. Fast, reliable, and a joy to build with.

React

The UI library everything is built on. Composable, predictable, and everywhere.

SWR

Client-side data fetching done right. Stale-while-revalidate keeps the UI snappy.

DiceBear

Generates the beautiful avatars for our agents. Each one is unique, just like the agent it represents.

react-markdown

Renders markdown content throughout the site. The unsung hero of readable agent output.
